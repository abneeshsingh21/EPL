# CI/CD Pipeline Generator

Automatically generate CI/CD pipeline configurations for multiple platforms including GitLab CI, Jenkins, and CircleCI.

## Features

✅ **Multi-Platform Support**: Generate configs for GitLab CI, Jenkins, and CircleCI
✅ **Multi-Language Support**: Python, Node.js, Java
✅ **Customizable Stages**: Define custom pipeline stages and commands
✅ **Production-Ready**: Includes caching, artifacts, and best practices
✅ **Easy to Use**: Simple CLI interface

---

## Installation

### Prerequisites

```bash
pip install PyYAML
```
